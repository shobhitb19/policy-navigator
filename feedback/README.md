# Feedback

Reviewer comments and feedback on the spatial policy position paper.

Drop files here in whatever form they arrive — tracked-changes Word documents,
emails, marked-up PDFs, notes. No naming convention required, though something
like `2026-08-27 <reviewer> on v1.5.docx` makes it easier to tell later which
version a comment was written against.

## Notes

- **This folder is not published.** `scripts/deploy_wiki.sh` copies only
  `claims`, `sources`, `synthesis`, `levers`, `places`, `concepts`, `evidence`,
  `docs`, `ontology` and `ingestion` to the live site. Like `outputs/`, anything
  here stays in the repo (private) and never reaches `gh-pages`.
- Feedback often names people or repeats things said in confidence. Keep that in
  mind before quoting any of it into the paper or the wiki — the source cards
  and claim cards are published, this folder is not.
- Paper versions live in `outputs/`. The current version is v1.5.
